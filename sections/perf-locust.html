Performance

Locust

Locust es la opción Python, code-first: modelás el comportamiento de un usuario como una clase con tareas. Trae una web UI para lanzar la prueba y ver métricas en vivo.

Heredás de HttpUser, marcás métodos con @task (con pesos para que unas acciones pasen más seguido que otras) y definís el wait_time (think time). Lo corrés con UI o --headless en CI, indicando usuarios (-u) y ramp-up (-r).

Python 
# locustfile.py — Locust: modelá el comportamiento de un usuario en Python.
from locust import HttpUser, task, between


class ShopUser(HttpUser):
    # Cada usuario simulado espera 1-3s entre acciones (think time).
    wait_time = between(1, 3)

    @task(3)              # peso 3: leé tres veces más seguido que el checkout
    def view_order(self):
        self.client.get("/orders/42")

    @task(1)
    def checkout(self):
        self.client.post("/orders", json={"items": ["book"]})


# Web UI:            locust -f locustfile.py --host https://api.example.com
# Headless (CI):     locust ... --headless -u 100 -r 10 -t 2m# locustfile.py — Locust: model a user's behavior in Python.

Manual vs AI

Manual A mano

Definís el escenario, los pesos de cada acción y los thresholds. El valor está en elegir bien qué simular y qué objetivo medir.

Con AI Con AI

La AI arma el esqueleto del script (k6/Locust) desde una descripción del flujo, sugiere thresholds razonables y te ayuda a interpretar los resultados (“tu p99 se dispara a partir de 150 VUs → posible cuello en la base”).

Próximo paso: elegí una herramienta (k6 si querés code-first y CI, JMeter si necesitás GUI/enterprise, Locust si tu equipo es Python), poné un SLO claro y empezá con el endpoint más crítico bajo carga realista.
