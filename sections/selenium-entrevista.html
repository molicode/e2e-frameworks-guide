Una entrevista simulada: preguntas típicas de este framework. Leé cada una, pensá cómo responderías y revelá una respuesta de referencia.

Reclutador

¿Cómo manejás las esperas para evitar tests flaky en Selenium?

Uso esperas explícitas (WebDriverWait + expected_conditions) por condiciones concretas, en vez de sleeps fijos; la implícita, con cuidado.

Reclutador

Contame cómo estructurarías un proyecto de automatización con Selenium.

Con Page Objects para encapsular páginas, un runner como pytest, datos de prueba separados, selectores estables (id/data-*) y reporte.

Reclutador

¿Cómo localizarías un elemento que no tiene id ni clase estable?

Por atributos semánticos (name, aria-label, texto) o relaciones cercanas; evito el XPath posicional que se rompe fácil.

Reclutador

¿Cómo corrés Selenium en CI y en paralelo?

En un pipeline con navegador headless; en paralelo con Selenium Grid o pytest-xdist.

Reclutador

¿Ventajas y desventajas frente a Playwright o Cypress?

Ventaja: estándar maduro, multi-lenguaje y multi-navegador. Desventaja: más verboso y sin auto-wait nativo, hay que manejar las esperas.

¿Cómo validás una respuesta de API dentro de un flujo de Selenium?

Selenium es de UI; para la API uso requests y verifico el status_code y el body por separado.
