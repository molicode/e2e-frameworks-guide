pytest: tu primer test

pytest es el runner de testing por excelencia en Python. Su superpoder: usás el assert común del lenguaje y pytest te muestra los valores cuando falla. Cero boilerplate para empezar.

Tu primer test

pytest descubre solo los archivos test_*.py y las funciones test_*. Cada función con un assert es un test. Corrés todo con pytest -q y ves en verde/rojo qué pasó.

Python 
# test_money.py — pytest descubre archivos test_*.py y funciones test_*.
def to_cents(amount):
    return round(amount * 100)


def test_converts_to_integer_cents():
    # Un assert simple es todo lo que pytest necesita — imprime los valores al fallar.
    assert to_cents(19.99) == 1999


def test_handles_zero():
    assert to_cents(0) == 0

# Corré toda la suite:  pytest -q# test_money.py — pytest discovers test_*.py files and test_* functions.
def to_cents(amount):
    return round(amount * 100)


def test_converts_to_integer_cents():
    # A plain assert is all pytest needs — it prints the values on failure.
    assert to_cents(19.99) == 1999


def test_handles_zero():
    assert to_cents(0) == 0

# Run the whole suite:  pytest -q

Fixtures y parametrización

Una fixture (@pytest.fixture) prepara datos o recursos reutilizables: cualquier test que pida ese nombre como parámetro lo recibe listo. Con @pytest.mark.parametrize corrés el mismo test sobre muchos casos sin repetir código.

Python 
# Las fixtures dan setup reutilizable; parametrize corre un test sobre muchas entradas.
import pytest


@pytest.fixture
def order():
    # Preparalo una vez; cualquier test que pida "order" recibe una copia fresca.
    return {"id": 42, "status": "PAID", "total": 250}


def test_order_is_paid(order):
    assert order["status"] == "PAID"


@pytest.mark.parametrize("amount,cents", [(1.0, 100), (19.99, 1999), (0, 0)])
def test_to_cents(amount, cents):
    assert round(amount * 100) == cents# Fixtures give reusable setup; parametrize runs one test on many inputs.

    # Arrange once; any test that asks for "order" gets a fresh copy.
    return {"id": 42, "status": "PAID", "total": 250}

    assert order["status"] == "PAID"

    assert round(amount * 100) == cents
Patrón AAA: incluso el test más simple sigue Arrange (preparar), Act (ejecutar) y Assert (verificar). Las fixtures son el lugar natural para el Arrange.
