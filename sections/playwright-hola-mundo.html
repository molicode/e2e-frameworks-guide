Setup y primer test

Con pip install pytest-playwright y playwright install tenés todo listo. Cada test es una función def test_nombre(page): … que recibe la fixture page. Corré pytest (headless) o pytest --headed para verlo en vivo.

Bash 
# Instalá pytest-playwright (el plugin oficial de testing para Python):
pip install pytest-playwright
playwright install        # descarga los binarios del navegador

# Ejecutá la suite (Chromium headless por defecto):
pytest

# Ejecutá en los tres motores, con interfaz gráfica:
pytest --browser chromium --browser firefox --browser webkit --headed# Install pytest-playwright (the official Python test plugin):
pip install pytest-playwright
playwright install        # downloads the browser binaries

# Run the suite (headless Chromium by default):
pytest

# Run across all three engines, headed:
pytest --browser chromium --browser firefox --browser webkit --headed
Python 
# test_login.py — pytest-playwright
from playwright.sync_api import Page, expect


def test_greets_the_user_after_login(page: Page):
    page.goto("https://example.com/login")

    # Los locators son lazy y autoesperan a que el elemento sea accionable.
    page.get_by_label("Username").fill("demo")
    page.get_by_label("Password").fill("secret")
    page.get_by_role("button", name="Sign in").click()

    # Las aserciones web-first reintentan hasta pasar o agotar el timeout.
    expect(page.get_by_text("Welcome, demo")).to_be_visible()# test_login.py — pytest-playwright
