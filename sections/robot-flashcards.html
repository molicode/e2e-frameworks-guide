🃏 Flashcards — repasá lo aprendido

Pregunta

¿Qué estilo de sintaxis usa Robot Framework?

Tocá la tarjeta para ver la respuesta
Respuesta

Keyword-driven: los tests se escriben con keywords legibles, casi lenguaje natural.

Pregunta

¿Qué es una librería en Robot (por ejemplo, SeleniumLibrary)?

Tocá la tarjeta para ver la respuesta
Respuesta

Un conjunto de keywords que aporta capacidades (navegador, HTTP, mobile, etc.).

Pregunta

¿Cómo se referencia una variable?

Tocá la tarjeta para ver la respuesta
Respuesta

Con la sintaxis ${nombre}; se asigna desde keywords o desde una sección de variables.

Pregunta

¿Para quién es ideal Robot?

Tocá la tarjeta para ver la respuesta
Respuesta

Equipos que quieren tests legibles por no-programadores y reutilización por keywords.

Pregunta

¿Cómo abrís un navegador con SeleniumLibrary?

Tocá la tarjeta para ver la respuesta
Respuesta

Con la keyword: Open Browser url chrome.

Pregunta

¿Cómo escribís en un campo?

Tocá la tarjeta para ver la respuesta
Respuesta

Con: Input Text id=user admin.

Pregunta

¿Cómo verificás que una página contiene un texto?

Tocá la tarjeta para ver la respuesta
Respuesta

Con: Page Should Contain Welcome.

Pregunta

¿Qué librería usás para HTTP/APIs?

Tocá la tarjeta para ver la respuesta
Respuesta

RequestsLibrary (GET/POST On Session, Status Should Be, etc.).

Pregunta

¿Qué es una keyword de usuario?

Tocá la tarjeta para ver la respuesta
Respuesta

Una keyword propia que agrupa pasos reutilizables.

Pregunta

¿Cómo se separan los argumentos?

Tocá la tarjeta para ver la respuesta
Respuesta

Con 2 o más espacios (o tabs) entre columnas.
