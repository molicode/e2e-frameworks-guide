Pregunta

¿Qué es WebDriver?

Tocá la tarjeta para ver la respuesta
Respuesta

El estándar W3C para controlar un navegador real de forma programática.

Pregunta

¿Espera implícita vs explícita?

Tocá la tarjeta para ver la respuesta
Respuesta

La implícita aplica a todas las búsquedas; la explícita espera una condición puntual (más robusta).

Pregunta

¿Qué es el patrón Page Object?

Tocá la tarjeta para ver la respuesta
Respuesta

Encapsular selectores y acciones de una página en una clase, para tests legibles y mantenibles.

Pregunta

¿Por qué evitar un sleep fijo?

Tocá la tarjeta para ver la respuesta
Respuesta

Hace los tests lentos y flaky; mejor esperar por condiciones (elemento visible o clickeable).

Pregunta

¿Cómo localizás un elemento por su id?

Tocá la tarjeta para ver la respuesta
Respuesta

Con driver.find_element(By.ID, "user").

Tocá la tarjeta para ver la respuesta
Respuesta

Escribe texto en un campo, simulando el tecleo del usuario.

Pregunta

Tocá la tarjeta para ver la respuesta
Respuesta

Leés su propiedad .text y lo comparás (assert elem.text == "...").
