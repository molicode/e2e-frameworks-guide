Appium (mobile)

Cada vez más producto vive en el celular. Appium es el estándar para automatizar apps nativas e híbridas de Android e iOS, con una API casi idéntica a la de Selenium WebDriver — así que lo que ya sabés se transfiere.

Setup

Appium es un servidor entre tu test y el dispositivo. Instalás el cliente (Appium-Python-Client), levantás el server con appium y necesitás un emulador/simulador o un device real, más el driver del SO (UiAutomator2 para Android, XCUITest para iOS).

Bash 
# Appium automatiza apps móviles REALES (Android/iOS) — como Selenium para teléfonos.
pip install Appium-Python-Client pytest

# Levantá el servidor de Appium (necesitás Node + los drivers UiAutomator2 / XCUITest):
appium

# También necesitás un emulador/simulador o un dispositivo real conectado.# Appium automates REAL mobile apps (Android/iOS) — like Selenium for phones.

Tu primer test mobile

Definís las capabilities (qué app, qué plataforma), abrís un webdriver.Remote apuntando al server y localizás elementos. En mobile, el accessibility id es el selector más robusto (equivale a un data-testid). De ahí en más, es como Selenium.

Python 
# test_login_mobile.py — manejá una app nativa con Appium (API similar a Selenium).
from appium import webdriver
from appium.options.android import UiAutomator2Options
from appium.webdriver.common.appiumby import AppiumBy


def test_login_on_android():
    options = UiAutomator2Options()
    options.app = "/apps/shop.apk"            # la app bajo prueba
    driver = webdriver.Remote("http://localhost:4723", options=options)
    try:
        driver.find_element(AppiumBy.ACCESSIBILITY_ID, "username").send_keys("demo")
        driver.find_element(AppiumBy.ACCESSIBILITY_ID, "password").send_keys("secret")
        driver.find_element(AppiumBy.ACCESSIBILITY_ID, "signin").click()
        banner = driver.find_element(AppiumBy.ACCESSIBILITY_ID, "welcome")
        assert banner.text == "Welcome, demo"
    finally:
        driver.quit()# test_login_mobile.py — drive a native app with Appium (Selenium-like API).

Manual vs AI

Manual A mano

Configurás capabilities, manejás emuladores y escribís cada interacción. Mobile suma fricción (dispositivos, gestos, permisos), pero el patrón es el mismo que en web.

Con AI Con AI

La AI te arma el esqueleto del test, recuerda las capabilities típicas de cada plataforma y traduce un flujo web a su equivalente mobile (gestos, scroll, esperas).

Próximo paso: empezá por el smoke test mobile más crítico (login, compra) en un emulador, integralo a CI con un device farm, y reusá tus Page Objects: la estrategia que aprendiste en web aplica igual.
