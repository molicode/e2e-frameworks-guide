Instalación y Hola mundo

Primero lo primero: tener Python instalado, crear un entorno aislado y correr un script. No necesitás un IDE pesado — un editor y la terminal alcanzan.

Instalación y entorno

Verificá tu versión con python3 --version. Para cada proyecto creá un entorno virtual (venv): aísla las dependencias para que no choquen entre proyectos. Activado el entorno, instalás librerías con pip.

Bash 
# Verificá que tengas Python 3 (3.9+ es una buena base para trabajo de QA):
python3 --version

# Creá un entorno virtual aislado para tu proyecto de tests:
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# Instalá las herramientas que más usa quien hace testing:
pip install pytest requests# Check you have Python 3 (3.9+ is a good baseline for QA work):
python3 --version

# Install the tools a tester reaches for most:

Tu primer script

Un archivo .py con un print ya es un programa. El if __name__ == "__main__": es el modismo para que cierto código corra solo cuando ejecutás el archivo directamente (y no cuando lo importás desde otro).

Python 
# hello.py — tu primer script de Python.
def main():
    name = "QA"
    # Las f-strings interpolan variables dentro de las { }:
    print(f"Hello, {name}! Ready to automate.")


# Este bloque corre solo cuando ejecutás el archivo directamente:
if __name__ == "__main__":
    main()

# Correlo desde la terminal:  python hello.py# hello.py — your first Python script.
def main():
    name = "QA"
    # f-strings interpolate variables right inside the { }:
    print(f"Hello, {name}! Ready to automate.")


# This block runs only when you execute the file directly:
if __name__ == "__main__":
    main()

# Run it from the terminal:  python hello.py
¡Listo! Si viste Hello, QA! en la terminal, ya tenés Python corriendo. Eso es el 80% de la batalla cuando recién empezás.
