Casos críticos

Los bugs más caros viven acá: plata y seguridad. Un total mal calculado o un permiso mal chequeado cuesta dinero y confianza. Esta sección reúne las pruebas que siempre conviene tener.

Regla de oro con dinero: nunca uses float para montos — trabajá en centavos (enteros). 0.1 + 0.2 no es 0.3 en JavaScript.

API testing (CRUD + auth)

Probás la API directamente: creás (POST → 201), leés (GET → 200) y validás el contrato de la respuesta. Y verificás la autenticación: sin token, 401; nunca un 200 silencioso.

JavaScript 
// API CRUD with auth — create, read, assert the contract. No UI.
const api = await request.newContext({
  baseURL: "https://api.example.com",
  extraHTTPHeaders: { Authorization: `Bearer ${token}` },
});

// CREATE
const created = await api.post("/orders", { data: { items: ["book"] } });
expect(created.status()).toBe(201);
const { id } = await created.json();

// READ + assert the response shape
const res = await api.get(`/orders/${id}`);
await expect(res).toBeOK();
expect(await res.json()).toMatchObject({ id, status: "NEW" });

// Without a token → 401 (not a silent 200 or a 500)
const anon = await request.get(`https://api.example.com/orders/${id}`);
expect(anon.status()).toBe(401);

Cuentas y recibos de pago

La matemática del recibo tiene que cerrar siempre: la suma de los ítems = subtotal, el impuesto exacto y subtotal + impuesto = total. Más los invariantes: nunca negativo, estado consistente con lo pagado.

JavaScript 
// Payment receipt — the money math must ALWAYS add up.
// Work in integer cents to avoid floating-point errors.
const r = await (await request.get("/api/receipts/9087")).json();

// Sum of line items equals the subtotal.
const itemsTotal = r.items.reduce((sum, it) => sum + it.cents, 0);
expect(itemsTotal).toBe(r.subtotalCents);                 // 9000

// Tax and total are exact.
expect(r.taxCents).toBe(Math.round(r.subtotalCents * 0.21)); // 1890
expect(r.totalCents).toBe(r.subtotalCents + r.taxCents);     // 10890

// Invariants: never negative, status consistent with the amount paid.
expect(r.totalCents).toBeGreaterThan(0);
expect(r.status).toBe("PAID");

Validación de valores

Donde más se cuela un bug: precisión decimal, redondeo y límites. Probá entradas que el formulario debe rechazar (negativos, cero, texto, demasiados decimales) y confirmá el formato de moneda.

JavaScript 
// Value validation — the classic money pitfalls QA must catch.

// 1) Never trust floats for money — work in integer cents.
expect(0.1 + 0.2).not.toBe(0.3);   // 0.30000000000000004 !
expect(10 + 20).toBe(30);          // cents are safe

// 2) Boundary inputs the form MUST reject:
for (const bad of ["-5", "0", "abc", "1e9", "10.999"]) {
  await page.getByLabel("Amount").fill(bad);
  await page.getByRole("button", { name: "Pay" }).click();
  await expect(page.getByText("Invalid amount")).toBeVisible();
}

// 3) Rounding is half-up and currency-formatted.
expect(formatMoney(1890)).toBe("$18.90");

Seguridad: autorización e IDOR

El control de acceso es crítico: el usuario A no debe poder leer la orden del usuario B con solo cambiar el id en la URL (eso es un IDOR). Debe responder 403, no 200.

JavaScript 
// Security — authorization & IDOR (Insecure Direct Object Reference).
// User A must NOT read User B's order just by changing the id in the URL.
const asUserA = await request.newContext({
  extraHTTPHeaders: { Authorization: `Bearer ${userAToken}` },
});

const res = await asUserA.get("/api/orders/99"); // belongs to user B
expect(res.status()).toBe(403);                  // forbidden, NOT 200

// No token at all → 401 (never a 500 or a silent 200).
const anon = await request.get("/api/orders/99");
expect(anon.status()).toBe(401);

Seguridad: inyección y validación de entrada

La app tiene que neutralizar la entrada maliciosa, no ejecutarla. Probás payloads de XSS y SQL injection: el texto debe mostrarse escapado (como texto literal) y nada debe romperse.

JavaScript 
// Security — the app must NEUTRALIZE malicious input, not run it.
const payloads = [
  "<script>alert(1)</script>",  // XSS
  "'; DROP TABLE orders;--",     // SQL injection
];

for (const p of payloads) {
  await page.getByLabel("Search").fill(p);
  await page.getByRole("button", { name: "Search" }).click();

  // The payload is shown as TEXT (escaped), never executed; nothing breaks.
  await expect(page.getByText(p)).toBeVisible();
  await expect(page.locator(".results")).toBeVisible();
}
Ojo: probá seguridad solo en apps propias o con autorización explícita. En sistemas de terceros, sin permiso, es ilegal.
