Reto: Login

Automatiza el login de la pantalla de la izquierda: completa las credenciales, envía el formulario y verifica que el usuario quedó adentro.

Sistema bajo prueba
example.com/login

Sign in

Email demo@acme.test getByLabel("Email")
Password ••••••••
Sign in getByRole("button", { name: "Sign in" })

after login → Welcome, demo getByText("Welcome")

Tu solución 0 / 3
TYPESCRIPT

Instrucciones

  1. 1
    Localiza los campos Usuario y Contraseña y complétalos.
    ¿Por qué importa?
    Un buen selector es la base de un test estable: prefiere roles y labels accesibles antes que clases CSS o XPath frágiles que cambian con el diseño.
    Hint (solución completa)
    TypeScript 
    cy.get('[name="user"]').type('ana');
cy.get('[name="password"]').type('s3cret!');
    Key terms:Selector / Locator
  2. 2
    Haz click en Iniciar sesión para enviar el formulario.
    ¿Por qué importa?
    No metas sleep fijos esperando la navegación: deja que el framework espere solo (auto-wait) a que el botón esté listo y la página responda.
    Hint (solución completa)
    TypeScript 
    cy.contains('button', 'Sign in').click();
    Key terms:Auto-wait / retryImplicit / Explicit / Fluent wait
  3. 3
    Verifica que aparezca el saludo Welcome con el usuario.
    ¿Por qué importa?
    Sin una aserción el test no prueba nada: afirma el estado final esperado (el saludo visible) para que falle si el login se rompe.
    Hint (solución completa)
    TypeScript 
    // Cypress retries the assertion until it passes or times out.
cy.contains('Welcome').should('be.visible');
    Key terms:Assertion
