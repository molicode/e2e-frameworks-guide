Robot Framework

Componentes clave

Una pantalla es la suma de muchos componentes. Acá tenés cómo testear los más comunes en este framework — fijate cómo casi siempre alcanzás el elemento por su rol accesible.

Formulario con validación

Verificás que aparezca el mensaje de error y que el botón de submit quede deshabilitado mientras el dato es inválido.

Robot Framework 
# Validación de formulario — aparece el error, el submit queda deshabilitado.
Input Text    id=email    not-an-email
Click Button    Sign up
Element Should Be Visible    css=.error
Element Should Be Disabled    css=button[type=submit]# Form validation — error shows, submit stays disabled.
Input Text    id=email    not-an-email
Click Button    Sign up
Element Should Be Visible    css=.error
Element Should Be Disabled    css=button[type=submit]

Select / dropdown

Elegís una opción con selectOption() y afirmás el valor seleccionado.

Robot Framework 
# Select / desplegable — elegí una opción y verificá el valor.
Select From List By Value    id=country    AR
${value}=    Get Selected List Value    id=country
Should Be Equal    ${value}    AR# Select / dropdown — pick an option and assert the value.
Select From List By Value    id=country    AR
${value}=    Get Selected List Value    id=country
Should Be Equal    ${value}    AR

Checkbox / toggle

Lo marcás con check() y verificás el estado con toBeChecked().

Robot Framework 
# Checkbox — seleccioná y verificá el estado.
Select Checkbox    name=optIn
Checkbox Should Be Selected    name=optIn# Checkbox — select and assert state.
Select Checkbox    name=optIn
Checkbox Should Be Selected    name=optIn

Modal / diálogo

Lo abrís, acotás las búsquedas al dialog, confirmás y verificás que se haya cerrado.

Robot Framework 
# Modal / diálogo — abrí, confirmá, verificá que desapareció.
Click Element    css=[data-action=delete]
Wait Until Element Is Visible    css=[role=dialog]
Click Button    Delete
Wait Until Element Is Not Visible    css=[role=dialog]# Modal / dialog — open, confirm, assert it's gone.
Click Element    css=[data-action=delete]
Wait Until Element Is Visible    css=[role=dialog]
Click Button    Delete
Wait Until Element Is Not Visible    css=[role=dialog]

Afirmás la cantidad de filas y el contenido de una celda puntual.

Toast / alerta

Verificás que aparezca (rol alert) y que luego desaparezca solo.

Robot Framework 
# Toast / alerta — aparece y después desaparece solo.
Click Element    css=[data-action=save]
Wait Until Element Is Visible    css=[role=alert]
Element Should Contain    css=[role=alert]    saved
Wait Until Element Is Not Visible    css=[role=alert]    timeout=8s# Toast / alert — appears, then disappears on its own.
Click Element    css=[data-action=save]
Wait Until Element Is Visible    css=[role=alert]
Element Should Contain    css=[role=alert]    saved
Wait Until Element Is Not Visible    css=[role=alert]    timeout=8s

Accesibilidad (a11y)

Escaneás la página con axe y afirmás cero violaciones. Bonus: buscar por rol y nombre hace tus tests resilientes y accesibles.

Robot Framework 
# Accesibilidad — no hay axe incorporado; los equipos envuelven axe-core en una
# librería propia, o verifican roles/labels directamente con keywords de SeleniumLibrary.
Element Attribute Value Should Be    css=button.icon    aria-label    Close
Page Should Contain Element    xpath=//*[@role='navigation']# Accessibility — there's no built-in axe; teams wrap axe-core in a custom
# library, or assert roles/labels directly with SeleniumLibrary keywords.
Element Attribute Value Should Be    css=button.icon    aria-label    Close
Page Should Contain Element    xpath=//*[@role='navigation']
