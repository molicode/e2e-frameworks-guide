Fundamentos del lenguaje

La sintaxis esencial que vas a usar en cada test: variables y tipos, condicionales y bucles, y funciones. Con esto ya podés leer y escribir la mayoría del código de automatización.

Variables y tipos

No declarás tipos: Python los infiere del valor. Los básicos son str (texto), int, float, bool y None. Los f-strings (f"...") interpolan variables dentro del texto y son tu herramienta diaria para mensajes y URLs.

Python 
# Python infiere el tipo a partir del valor — no hace falta declararlo.
name = "Ada"          # str
attempts = 3          # int
price = 19.99         # float
is_active = True      # bool
nothing = None        # el valor "sin valor"

# Los tipos son dinámicos pero fuertes: no los mezcla en silencio.
print(type(name), type(attempts))   # <class 'str'> <class 'int'>
total = price * attempts             # 59.97
label = f"{name} has {attempts} attempts"   # f-string# Python infers the type from the value — no declarations needed.
name = "Ada"          # str
attempts = 3          # int
price = 19.99         # float
is_active = True      # bool
nothing = None        # the "no value" value

# Types are dynamic but strong: it won't silently mix them.
print(type(name), type(attempts))   # <class 'str'> <class 'int'>
total = price * attempts             # 59.97
label = f"{name} has {attempts} attempts"   # f-string

Condicionales y bucles

El control de flujo usa indentación (4 espacios), no llaves. if/elif/else para decidir; for para recorrer cualquier iterable y while para repetir mientras se cumpla una condición. continue saltea una vuelta y break corta el bucle.

Python 
# Los condicionales usan indentación (sin llaves) — la convención es 4 espacios.
status = "PAID"
if status == "PAID":
    print("Charged")
elif status == "NEW":
    print("Pending")
else:
    print("Other state")

# Bucles: for-each sobre cualquier iterable, while para una condición.
for i in range(3):          # 0, 1, 2
    print("attempt", i)

names = ["Ada", "Linus", "Grace"]
for n in names:
    if n == "Linus":
        continue            # salteá este
    print(n)# Conditionals use indentation (no braces) — 4 spaces is the convention.
status = "PAID"
if status == "PAID":
    print("Charged")
elif status == "NEW":
    print("Pending")
else:
    print("Other state")

# Loops: for-each over any iterable, while for a condition.
for i in range(3):          # 0, 1, 2
    print("attempt", i)

names = ["Ada", "Linus", "Grace"]
for n in names:
    if n == "Linus":
        continue            # skip this one
    print(n)

Funciones

Definís funciones con def, con parámetros (que pueden tener valores por defecto) y un return. En Python las funciones son valores: podés pasarlas como argumento, lo que es la base de fixtures y hooks en los frameworks de testing.

Python 
# Funciones: def, parámetros con valor por defecto opcional, un valor de retorno.
def total_cents(price, qty=1):
    """Return price * quantity as integer cents."""
    return round(price * qty * 100)


# Llamá por posición o por palabra clave:
print(total_cents(19.99))          # 1999
print(total_cents(19.99, qty=3))   # 5997

# Las funciones son valores — podés pasarlas (útil para fixtures/hooks).
def apply(fn, value):
    return fn(value)# Functions: def, optional default params, a return value.
