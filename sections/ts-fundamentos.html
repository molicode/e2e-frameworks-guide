TypeScript

Fundamentos del lenguaje

La sintaxis esencial: variables tipadas, control de flujo y funciones. Lo mismo que en JavaScript, pero con tipos que te cubren.

Variables y tipos

Anotás tipos con : tipo, pero TS también los infiere del valor. Los básicos: string, number, boolean. Usá const por defecto (no se reasigna) y let solo cuando necesitás cambiar el valor. El compilador caza los errores de tipo antes de correr.

TypeScript 
// Anotás tipos con ": tipo", pero TS también los INFIERE desde el valor.
const name: string = "Ada";
let attempts = 3;           // inferido como number
const price = 19.99;        // number
const isActive = true;      // boolean

// "const" no se puede reasignar; "let" sí. Preferí const por defecto.
attempts = attempts + 1;    // ok
// price = 20;              // error de compilación: price es const

// El compilador detecta errores de tipo ANTES de ejecutar:
const label = `${name} has ${attempts} attempts`;// You annotate types with ": type", but TS also INFERS them from the value.
const name: string = "Ada";
let attempts = 3;           // inferred as number
const price = 19.99;        // number
const isActive = true;      // boolean

// "const" can't be reassigned; "let" can. Prefer const by default.
attempts = attempts + 1;    // ok
// price = 20;              // compile error: price is const

// The compiler catches type mistakes BEFORE you run:
const label = `${name} has ${attempts} attempts`;

Condicionales y bucles

El control de flujo usa llaves: if/else if/else para decidir, for...of para recorrer los valores de un iterable y while para una condición. continue saltea una vuelta y break corta el bucle.

TypeScript 
// El control de flujo usa llaves. if / else if / else para decidir.
const status = "PAID";
if (status === "PAID") {
  console.log("Charged");
} else if (status === "NEW") {
  console.log("Pending");
} else {
  console.log("Other state");
}

// for...of recorre los valores de cualquier iterable:
const names = ["Ada", "Linus", "Grace"];
for (const n of names) {
  if (n === "Linus") continue; // salteá este
  console.log(n);
}// Control flow uses braces. if / else if / else to decide.
const status = "PAID";
if (status === "PAID") {
  console.log("Charged");
} else if (status === "NEW") {
  console.log("Pending");
} else {
  console.log("Other state");
}

// for...of walks the values of any iterable:
const names = ["Ada", "Linus", "Grace"];
for (const n of names) {
  if (n === "Linus") continue; // skip this one
  console.log(n);
}

Funciones

Definís funciones con parámetros tipados (opcionales con ?, con valor por defecto con =) y un tipo de retorno. Las arrow functions (=>) son concisas y aparecen en todo el código de test. Las funciones son valores: podés pasarlas como argumento.

TypeScript 
// Funciones: params tipados (opcionales con ?, defaults con =) y un tipo de retorno.
function totalCents(price: number, qty: number = 1): number {
  return Math.round(price * qty * 100);
}

// Las arrow functions son concisas y están por todos lados en el código de tests:
const double = (n: number): number => n * 2;

// Las funciones son valores — pasalas de un lado a otro (la base de hooks/fixtures):
function apply<T>(fn: (v: T) => T, value: T): T {
  return fn(value);
}
console.log(totalCents(19.99, 3)); // 5997// Functions: typed params (optional with ?, defaults with =) and a return type.
function totalCents(price: number, qty: number = 1): number {
  return Math.round(price * qty * 100);
}

// Arrow functions are concise and everywhere in test code:
const double = (n: number): number => n * 2;

// Functions are values — pass them around (the basis of hooks/fixtures):
function apply<T>(fn: (v: T) => T, value: T): T {
  return fn(value);
}
console.log(totalCents(19.99, 3)); // 5997
