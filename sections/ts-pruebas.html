Vitest: tu primer test

Vitest (compatible con la API de Jest) es un runner rapidísimo para TypeScript. Organizás con describe/it y afirmás con expect(...). Ideal para tu primer test.

Tu primer test

Un test es una función dentro de it("...", () => { ... }), agrupada en un describe. La aserción es expect(actual).toBe(esperado) y muestra ambos valores cuando falla. Corrés todo con npx vitest run.

TypeScript 
// money.test.ts — Vitest (su API es compatible con Jest).
import { describe, it, expect } from "vitest";

function toCents(amount: number): number {
  return Math.round(amount * 100);
}

describe("toCents", () => {
  it("converts to integer cents", () => {
    // expect(...).toBe(...) es la aserción; imprime ambos valores al fallar.
    expect(toCents(19.99)).toBe(1999);
  });

  it("handles zero", () => {
    expect(toCents(0)).toBe(0);
  });
});

// Corré la suite:  npx vitest run// money.test.ts — Vitest (its API is Jest-compatible).

Hooks y casos múltiples

beforeEach prepara un estado fresco antes de cada test, así no se filtran datos entre ellos. Con it.each corrés el mismo test sobre muchos casos sin repetir código — el equivalente a la parametrización.

TypeScript 
// beforeEach prepara estado fresco; it.each corre un test sobre muchos casos.
import { describe, it, expect, beforeEach } from "vitest";

describe("order", () => {
  let order: { id: number; status: string };

  beforeEach(() => {
    // Preparás una vez antes de CADA test — no se filtra estado entre tests.
    order = { id: 42, status: "PAID" };
  });

  it("is paid", () => {
    expect(order.status).toBe("PAID");
  });

  it.each([
    [1.0, 100],
    [19.99, 1999],
    [0, 0],
  ])("toCents(%d) === %d", (amount, cents) => {
    expect(Math.round(amount * 100)).toBe(cents);
  });
});// beforeEach prepares fresh state; it.each runs one test over many cases.
import { describe, it, expect, beforeEach } from "vitest";

describe("order", () => {
  let order: { id: number; status: string };

  beforeEach(() => {
    // Arrange once before EACH test — no state leaks between tests.
    order = { id: 42, status: "PAID" };
  });

  it("is paid", () => {
    expect(order.status).toBe("PAID");
  });

  it.each([
    [1.0, 100],
    [19.99, 1999],
    [0, 0],
  ])("toCents(%d) === %d", (amount, cents) => {
    expect(Math.round(amount * 100)).toBe(cents);
  });
});
Patrón AAA: hasta el test más simple sigue Arrange, Act y Assert. beforeEach es el lugar natural para el Arrange.
