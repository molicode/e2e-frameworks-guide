Bibliografía

Fuentes oficiales y recursos de referencia para profundizar. Los enlaces abren en una pestaña nueva.

Selenium 3
  • Selenium — Documentation Documentación oficial: instalación, WebDriver, esperas y grid.
  • W3C WebDriver (specification) La especificación W3C del protocolo WebDriver.
  • SeleniumHQ/selenium — GitHub Código fuente, releases e issues del proyecto.
Cypress 3
  • Cypress — Documentation Guías, API y conceptos centrales.
  • Cypress — Best Practices Buenas prácticas oficiales: selectores, aislamiento y anti-patrones.
  • cypress-io/cypress — GitHub Código fuente, releases e issues del proyecto.
Playwright 4
  • Playwright — Documentation Introducción, configuración y test runner.
  • Playwright — Best Practices Buenas prácticas oficiales para tests resilientes.
  • Playwright — Locators Guía de locators (getByRole, getByLabel, filtros).
  • microsoft/playwright — GitHub Código fuente, releases e issues del proyecto.
Robot Framework 4
  • Robot Framework — User Guide Guía de usuario oficial: sintaxis, keywords, variables y librerías.
  • SeleniumLibrary Librería para manejar el navegador con Selenium WebDriver.
  • Browser library (Playwright-based) Librería moderna de navegador basada en Playwright.
  • RequestsLibrary Librería para testear APIs HTTP (GET, POST, PUT, DELETE…).
BDD / Gherkin 3
  • Cucumber — Documentation Documentación de Cucumber: cómo escribir y ejecutar escenarios.
  • Gherkin — Reference Referencia del lenguaje Gherkin: Given / When / Then.
  • pytest-bdd BDD en Python sobre pytest: liga los .feature con los steps.
Performance 3
  • k6 — Documentation Tests de carga como código en JavaScript, con thresholds.
  • Apache JMeter — User Manual La herramienta clásica de carga: planes, samplers y reportes.
  • Locust — Documentation Tests de carga en Python definiendo el comportamiento del usuario.
Skills de QA 5
  • Appium — Documentation Automatización mobile (Android e iOS) con el protocolo WebDriver.
  • GitHub Actions — Documentation CI/CD en GitHub: workflows, jobs, matrices y artefactos.
  • Pro Git (book, free) El libro oficial de Git, gratis y completo, para dominar el control de versiones.
  • SQLBolt — Interactive SQL Curso interactivo para aprender SQL desde cero en el navegador.
  • MDN — HTTP request methods Referencia de los métodos HTTP: qué hace cada verbo.
Estándares y certificaciones 4
  • ISTQB — Certifications El catálogo de certificaciones de testing reconocidas en la industria.
  • ISTQB — Certified Tester Finance Testing (CT-FT) Certificación enfocada en el testing del dominio financiero.
  • TMMi Foundation Modelo de madurez para medir y mejorar procesos de testing.
  • ISO 9001 — Quality management El estándar de gestión de calidad de referencia mundial.
Testing (general) 6
  • Martin Fowler — The Practical Test Pyramid El artículo de referencia sobre la pirámide de testing.
  • Kent C. Dodds — The Testing Trophy El “trofeo” de testing: otra mirada sobre dónde invertir.
  • ISTQB — Glossary Glosario estándar de la industria con cientos de términos.
  • Testing Library Filosofía de tests centrados en el usuario y queries por rol.
  • MDN — CSS selectors Referencia de selectores CSS.
  • W3C — ARIA Authoring Practices Roles y patrones ARIA: la base de getByRole.
AI en QA 4
  • Anthropic — Documentation Docs de Claude: prompts, tool use, agentes y MCP.
  • Model Context Protocol (MCP) Sitio oficial del Model Context Protocol.
  • Prompt Engineering Guide Guía abierta de prompt engineering con técnicas y ejemplos.
  • OpenAI — Prompt engineering Guía de prompt engineering de OpenAI.
