TypeScript

Tipos, objetos y arrays

El corazón de TypeScript: describir la forma de tus datos. Interfaces, arrays tipados y JSON son lo que vas a tocar en cada test de API.

Interfaces y objetos

Una interface (o type) describe la forma de un objeto: qué campos tiene y de qué tipo. Es el contrato de tu API expresado en código. Podés marcar propiedades opcionales con ? y limitar valores con uniones ("NEW" | "PAID").

TypeScript 
// Una interface describe la FORMA de un objeto — tus contratos de API en código.
interface Order {
  id: number;
  status: "NEW" | "PAID" | "REFUNDED"; // una unión de valores permitidos
  total: number;
  coupon?: string;                     // propiedad opcional
}

const order: Order = { id: 42, status: "PAID", total: 250 };

// El compilador ahora protege cada acceso:
console.log(order.status);   // ok
// order.status = "DONE";    // error: no está en la unión// An interface describes the SHAPE of an object — your API contracts in code.
interface Order {
  id: number;
  status: "NEW" | "PAID" | "REFUNDED"; // a union of allowed values
  total: number;
  coupon?: string;                     // optional property
}

const order: Order = { id: 42, status: "PAID", total: 250 };

// The compiler now guards every access:
console.log(order.status);   // ok
// order.status = "DONE";    // error: not in the union

Arrays y transformaciones

Los arrays se tipan (number[]). map, filter y reduce son tus transformaciones diarias, y every/some se leen como aserciones sobre toda una colección ("todos los precios son positivos").

TypeScript 
// Los arrays son tipados; map/filter/reduce son tus transformaciones diarias.
const prices: number[] = [10, 25, 7, 50];
const withTax = prices.map((p) => Math.round(p * 121) / 100); // [12.1, 30.25, 8.47, 60.5]
const expensive = prices.filter((p) => p > 20);               // [25, 50]
const sum = prices.reduce((acc, p) => acc + p, 0);            // 92

// every() / some() se leen como aserciones sobre una colección:
const allPositive = prices.every((p) => p > 0); // true// Arrays are typed; map/filter/reduce are your daily transforms.
const prices: number[] = [10, 25, 7, 50];
const withTax = prices.map((p) => Math.round(p * 121) / 100); // [12.1, 30.25, 8.47, 60.5]
const expensive = prices.filter((p) => p > 20);               // [25, 50]
const sum = prices.reduce((acc, p) => acc + p, 0);            // 92

// every() / some() read like assertions over a collection:
const allPositive = prices.every((p) => p > 0); // true

JSON

Las APIs hablan JSON. JSON.parse convierte texto a objeto y JSON.stringify de vuelta a texto. Le podés afirmar la forma con as. En la práctica, fetch ya te da el body parseado con await res.json().

TypeScript 
// Las APIs hablan JSON; JSON.parse/stringify convierten texto <-> objetos.
const raw = '{"id": 42, "items": ["book"], "total": 250}';
const order = JSON.parse(raw) as { id: number; items: string[]; total: number };
console.log(order.items[0]); // book

// Objeto -> texto JSON (el 2 agrega indentación para diffs de test legibles):
const payload = JSON.stringify({ status: "PAID" }, null, 2);

// fetch hace esto por vos: await res.json() devuelve el body parseado.// APIs speak JSON; JSON.parse/stringify convert text <-> objects.
const raw = '{"id": 42, "items": ["book"], "total": 250}';
const order = JSON.parse(raw) as { id: number; items: string[]; total: number };
console.log(order.items[0]); // book

// Object -> JSON text (the 2 adds indentation for readable test diffs):
const payload = JSON.stringify({ status: "PAID" }, null, 2);

// fetch does this for you: await res.json() returns the parsed body.
