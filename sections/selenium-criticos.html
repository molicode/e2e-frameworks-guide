API testing (CRUD + auth)

Probás la API directamente, cubriendo todos los verbos: creás (POST → 201), leés (GET → 200), actualizás (PATCH/PUT → 200) y borrás (DELETE → 204, y un GET posterior da 404). Validás el contrato de cada respuesta y la autenticación: sin token, 401; nunca un 200 silencioso.

Python 
# Testing de API en un proyecto Selenium — Selenium maneja la UI; la capa de
# API usa un cliente HTTP simple como requests. Cubrí todo el contrato CRUD.
import requests

base = "https://api.example.com"
auth = {"Authorization": f"Bearer {token}"}

# CREATE (POST) -> 201 + el id nuevo
created = requests.post(f"{base}/orders", json={"items": ["book"]}, headers=auth)
assert created.status_code == 201
order_id = created.json()["id"]

# READ (GET) -> 200 + la forma esperada
got = requests.get(f"{base}/orders/{order_id}", headers=auth)
assert got.status_code == 200
assert got.json()["status"] == "NEW"

# UPDATE (PATCH) -> 200 + el cambio persistido
patched = requests.patch(f"{base}/orders/{order_id}", json={"status": "PAID"}, headers=auth)
assert patched.status_code == 200
assert patched.json()["status"] == "PAID"

# DELETE -> 204, y luego un GET da 404
assert requests.delete(f"{base}/orders/{order_id}", headers=auth).status_code == 204
assert requests.get(f"{base}/orders/{order_id}", headers=auth).status_code == 404

# Sin token -> 401, nunca un 200 silencioso.
assert requests.get(f"{base}/orders/{order_id}").status_code == 401# API testing in a Selenium project — Selenium drives the UI; the API

Cuentas y recibos de pago

La matemática del recibo tiene que cerrar siempre: la suma de los ítems = subtotal, el impuesto exacto y subtotal + impuesto = total. Más los invariantes: nunca negativo, estado consistente con lo pagado.

Python 
# Montos (Selenium) — leé los campos de dinero y verificá la cuenta en centavos.
import re

driver.get("https://pay.example.com/receipts/9087")
cents = lambda s: round(float(re.sub(r"[^0-9.]", "", s)) * 100)

sub = cents(driver.find_element(By.CSS_SELECTOR, ".subtotal").text)
tax = cents(driver.find_element(By.CSS_SELECTOR, ".tax").text)
total = cents(driver.find_element(By.CSS_SELECTOR, ".total").text)

assert tax == round(sub * 0.21)  # impuesto exacto
assert total == sub + tax        # subtotal + impuesto = total
assert total > 0                 # nunca negativo# Amounts (Selenium) — read the money fields and assert the math in cents.

Validación de documentos legales

Facturas, contratos o comprobantes: validás que estén los campos obligatorios, el formato del número, el estado (firmado) y que la fecha no sea futura.

Python 
# Validación de documento legal (Selenium) — campos requeridos y formato de una factura.
import re
from datetime import date

driver.get("https://app.example.com/invoices/INV-2026-0042")
text = lambda sel: driver.find_element(By.CSS_SELECTOR, sel).text.strip()

assert re.match(r"^INV-\d{4}-\d{4}$", text(".invoice-number"))  # formato del ID
assert len(text(".tax-id")) > 0                                  # presente
assert text(".doc-status") == "SIGNED"                           # firmado
assert date.fromisoformat(text(".issued-date")) <= date.today()  # no futura# Legal document validation (Selenium) — an invoice's required fields & format.

Seguridad: autorización e IDOR

El control de acceso es crítico: el usuario A no debe poder leer la orden del usuario B con solo cambiar el id en la URL (eso es un IDOR). Debe responder 403, no 200.

Python 
# Seguridad (proyecto Selenium) — autorización/IDOR + manejo de entradas.
import requests

# El usuario A NO debe leer la factura del usuario B cambiando el id.
res = requests.get(
    "https://api.example.com/invoices/INV-2026-0099",
    headers={"Authorization": f"Bearer {user_a_token}"},
)
assert res.status_code == 403  # prohibido, NO 200

# XSS: un payload de script debe mostrarse como texto, nunca ejecutarse.
driver.get("https://app.example.com/search?q=%3Cscript%3Ealert(1)%3C/script%3E")
shown = driver.find_element(By.CSS_SELECTOR, ".results").text
assert "<script>alert(1)</script>" in shown  # escapado, literal# Security (Selenium project) — authorization/IDOR + input handling.
import requests

# User A must NOT read user B's invoice by changing the id.
res = requests.get(
    "https://api.example.com/invoices/INV-2026-0099",
    headers={"Authorization": f"Bearer {user_a_token}"},
