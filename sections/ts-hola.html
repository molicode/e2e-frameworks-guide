TypeScript

Instalación y Hola mundo

Lo primero: tener Node, agregar TypeScript y poder ejecutar un archivo .ts sin compilar a mano. Con tsx corrés TypeScript directo.

Instalación y proyecto

Verificá Node con node --version. Iniciás el proyecto con npm init -y e instalás typescript y un runner rápido como vitest. Con tsc --init generás el tsconfig.json que configura el compilador.

Bash 
# Verificá que Node esté instalado (18+ es una buena base):
node --version

# Iniciá un proyecto y agregá TypeScript + un test runner rápido:
npm init -y
npm install --save-dev typescript tsx vitest

# Creá un tsconfig.json con valores por defecto sensatos:
npx tsc --init# Check Node is installed (18+ is a good baseline):
node --version

# Start a project and add TypeScript + a fast test runner:
npm init -y
npm install --save-dev typescript tsx vitest

# Create a tsconfig.json with sensible defaults:
npx tsc --init

Tu primer archivo

Un archivo .ts con una función ya es un programa. Anotás el tipo de los parámetros y del retorno con : tipo, y el compilador te avisa si algo no cuadra. Con npx tsx hello.ts lo ejecutás sin un paso de build.

TypeScript 
// hello.ts — tu primer archivo TypeScript.
function greet(name: string): string {
  // Los template literals interpolan con ${ }, y el tipo de retorno se verifica.
  return `Hello, ${name}! Ready to automate.`;
}

console.log(greet("QA"));

// Corré sin compilar primero:  npx tsx hello.ts// hello.ts — your first TypeScript file.
function greet(name: string): string {
  // Template literals interpolate with ${ }, and the return type is checked.
  return `Hello, ${name}! Ready to automate.`;
}

console.log(greet("QA"));

// Run it without compiling first:  npx tsx hello.ts
¡Listo! Si viste Hello, QA! en la terminal, ya tenés TypeScript corriendo. El resto es construir sobre eso.
